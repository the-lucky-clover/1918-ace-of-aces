# 1918: Ace of Aces

A WWI shoot-em-up web game. Free to play, single-file HTML5 build — no build step, no dependencies.

## Play

Open `1918-ace-of-aces.html` in any modern browser, or serve the directory:

```
python3 -m http.server 8000
```

then visit http://localhost:8000/1918-ace-of-aces.html

## Features

- 194X-style arcade combat over the Western Front
- Six mission-specific sorties + three-phase boss fights
- Hat-in-the-Ring SPAD XIII (94th Aero Squadron livery)
- Mission debriefing, rank promotions, medal/ribbon awards
- Wingman Link: remote 2-player co-op over WebRTC (host/join + QR code)
- In-game Field Almanac with the full lore
- Period-evocative synthesized score and combat SFX

## Notes

This is the single-file web build. Native iOS/Android ports (with AdMob + $2.99 ad-removal IAP) are the roadmap — see the project goal.
